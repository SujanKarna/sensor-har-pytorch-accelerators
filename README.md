Sensor-Based Human Activity Recognition with PyTorch

An experimental deep learning project focused on multivariate time-series classification using inertial sensor data. The project explores the implementation, training, and evaluation of neural network models with PyTorch, followed by experiments across different hardware accelerators.

The goal is to develop a practical understanding of sensor-data analysis, deep learning workflows, and hardware-aware model execution.

Project Overview

Human Activity Recognition (HAR) involves identifying physical activities from sensor measurements collected by devices such as smartphones and wearable sensors.

This project uses the UCI Human Activity Recognition Using Smartphones dataset, which contains accelerometer and gyroscope recordings from 30 participants performing six activities.

The primary focus is to build a deep learning pipeline that processes raw inertial sensor signals and classifies human activities.

Beyond model development, the project investigates how the same model behaves across different computing platforms.
